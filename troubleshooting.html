04 / TROUBLESHOOTING

Diagnose before changing code

Many storefront issues are caused by store configuration, missing resources or preview tooling rather than theme code. Use this checklist before editing files.

A section is empty

  • Open the section in the Theme Editor and confirm it is enabled.
  • Check whether the section requires a collection, menu, image or other resource.
  • Confirm that the referenced resource still exists and contains usable content.
  • Preview the published storefront rather than relying only on an editor preview.

Products are missing

  • Confirm the collection contains products.
  • Confirm products are available to the relevant sales channel/market.
  • Check product publication status, inventory and market availability.
  • Confirm the section is assigned to the intended collection.

Navigation is incorrect

Open Shopify's menu management and verify the menu assigned to the theme section. Check every link target and nested item. Avoid relying on hardcoded URLs when the destination should be configurable by the merchant.

Images appear wrong or cropped

Check the image selected in the section settings, then review the section's image ratio, focal-point and object-fit controls where available. Different source images can require different crops, especially between desktop and mobile.

Cart behavior looks incorrect

Test with a real product and a clean browser session. Verify product availability, variant selection and Shopify cart configuration. If the issue occurs only in a development preview, repeat the test on the storefront URL.

Theme Editor changes do not appear

  • Confirm the changes were saved.
  • Confirm you are viewing the same theme instance you edited.
  • Hard-refresh the browser if an asset appears cached.
  • Check whether the section is hidden on the current template.

Performance concerns

Use Lighthouse on the actual storefront and test the Home, Product and Collection pages on both desktop and mobile. Large images, excessive third-party scripts, apps and merchant content can materially affect performance independently of theme code.

When contacting support

Send the store URL, theme version, affected template/page, exact reproduction steps, expected behavior, actual behavior and screenshots or screen recordings when useful. Do not send passwords, private access tokens or other credentials.
