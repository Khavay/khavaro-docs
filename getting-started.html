01 / GETTING STARTED

Set up Khavaro

Use this sequence for a clean first installation. Khavaro is configured through Shopify's standard theme and content-management interfaces; no code editing is required for normal merchant setup.

1. Install the theme

  1. In Shopify admin, open Online Store → Themes.
  2. Add or upload the Khavaro theme package using Shopify's theme upload workflow.
  3. Open Customize to enter the Theme Editor.
  4. Work on the theme as a draft until your navigation, products, collections and policies are ready.

2. Configure the brand

Open Theme settings and configure the logo, favicon, typography, color schemes, buttons, cards and other global presentation controls. Khavaro's visual system is intentionally minimal: sharp edges, restrained contrast and editorial typography.

3. Create the store structure

Before configuring the homepage, make sure the store has the resources that sections can reference:

  • Products with titles, descriptions, prices, media and variants where applicable.
  • Collections for the categories you want to merchandise.
  • Navigation menus for the main header, mega menu and footer.
  • Pages such as About, FAQ, Contact or other brand-specific content as required.
  • Store policies and checkout settings configured in Shopify admin.

4. Configure the homepage

Go to Online Store → Themes → Customize and open the Home page. Khavaro's supplied homepage uses a sequence of editorial and merchandising sections including a marquee/ticker, hero presentation, promotional content, new arrivals, category split, editorial/press content, brand story, lookbook/collection content and newsletter/footer areas.

5. Configure navigation

Use Shopify's Content → Menus area to create and maintain the links used by the storefront. The desktop header supports multi-level navigation and a mega-menu presentation; the mobile experience uses a dedicated drawer layout.

6. Configure products and collections

Assign the appropriate collection to merchandising sections and ensure product media, variants and inventory are correct before launch. Product and collection templates are designed to work with Shopify's native product and collection objects rather than requiring fixed product handles.

7. Final pre-launch check

  • Logo and favicon are correct.
  • Main menu and footer menu point to real storefront destinations.
  • Every featured collection is assigned correctly.
  • Product variants, prices, inventory and purchase controls have been tested.
  • Collection filtering/sorting and pagination have been tested with a realistic catalog.
  • Cart, checkout and policy links have been tested.
  • Desktop and mobile layouts have been reviewed in the Shopify Theme Editor and storefront.
Important: Khavaro's included default presentation is a starting configuration. Replace merchant-specific text, claims, links, images and collection assignments with your own store content before publishing.
