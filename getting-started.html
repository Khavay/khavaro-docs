01 / GETTING STARTED

Set up Khavaro

Use this sequence for a clean first installation. Normal merchant setup is handled through Shopify's standard theme and content-management interfaces.

1. Install the theme

  1. In Shopify admin, open Online Store → Themes.
  2. Add or upload the Khavaro theme package using Shopify's theme upload workflow.
  3. Open Customize to enter the Theme Editor.
  4. Keep the theme as a draft while navigation, products, collections and policies are prepared.

2. Configure the brand

Open Theme settings and configure the logo, favicon, typography, color schemes, buttons, cards and global presentation controls.

3. Create the store structure

  • Products with titles, descriptions, prices, media and variants where applicable.
  • Collections for the categories you want to merchandise.
  • Navigation resources for the main header, mega menu and footer.
  • Brand pages such as About, FAQ and Contact where required.
  • Store policies, payments, shipping and checkout settings in Shopify admin.

4. Configure the home page

Open Online Store → Themes → Customize and select the Home page. Review the supplied editorial and merchandising sections, then replace merchant-specific copy, images, links and collection assignments with accurate store content.

5. Configure navigation

Use Shopify's Content → Menus area to maintain the links used by the storefront. Desktop navigation supports deeper structures through the mega menu; mobile navigation uses a dedicated drawer experience.

6. Configure products and collections

Assign the intended collections to merchandising sections and verify product media, variants, inventory, publication status and market availability.

7. Final pre-launch check

  • Logo and favicon are correct.
  • Main menu and footer menu point to real destinations.
  • Featured collections are assigned correctly.
  • Product variants, prices, inventory and purchase controls have been tested.
  • Collection filtering, sorting, pagination and empty states have been reviewed.
  • Cart, checkout and policy links have been tested.
  • Desktop and mobile layouts have been reviewed in the Theme Editor and storefront.
Important: The supplied configuration is a starting point. Replace merchant-specific claims, links, images, shipping statements, testimonials and collection assignments with information that is true for the store.
