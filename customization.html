02 / CUSTOMIZATION

Shape the storefront

Most visual and merchandising decisions should be made in Shopify's Theme Editor. Keep code editing for advanced development and maintenance only.

Global theme settings

AreaWhat to configure
LogoBrand logo, logo width and favicon.
ColorsColor schemes for backgrounds, text, buttons, borders and supporting UI.
TypographyHeading and body font selections and scale controls.
LayoutPage width, section spacing and grid spacing.
ButtonsBorder, radius, opacity and shadow presentation.
CardsProduct, collection and editorial card presentation.
MediaMedia ratio, borders, radius and presentation behavior where available.

Home page sections

Hero

Use the hero controls to configure the opening message, calls to action and campaign imagery. Replace supplied visuals and claims with the merchant's own content.

New Arrivals

Select the collection to merchandise, configure the product limit and adjust the section heading and view-all destination.

Category split

Use category content to direct shoppers toward major collections or curated storefront destinations. Configure labels, links and associated resources through the section settings.

Editorial, brand story and lookbook

These sections are intended for brand positioning and visual storytelling. Replace supplied copy and imagery with accurate merchant content.

Newsletter

Configure the newsletter section for legitimate marketing communications and connect it to the store's chosen Shopify-compatible customer/newsletter workflow.

Header and mega menu

The header uses Shopify navigation resources and supports a desktop mega-menu presentation. Keep the hierarchy concise and make the top-level categories understandable at a glance. Mobile navigation uses a dedicated drawer.

Product page

The product template uses Shopify's product object and supports product details, variants, media, purchase controls and related-product merchandising. Use content blocks for materials, care, fit, sizing and shipping/returns information.

Collection page

The collection template presents collection content and a product grid with merchandising controls. Configure the actual collection in Shopify admin and use the Theme Editor for presentation settings.

Localization and markets

Use Shopify's native localization, markets, currency and customer-account configuration. Avoid hardcoding merchant-specific destinations when a Shopify resource can be selected instead.

Merchant content rule: Do not publish example shipping thresholds, return policies, press mentions, manufacturing locations, sustainability claims or testimonials unless they accurately describe the merchant's business.
