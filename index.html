khay —
Luxury Editorial
Shopify Theme

A refined, editorial Shopify theme built on the Dawn architecture for fashion houses and luxury brands. Warm ivory grounds, Cormorant display typography, and a refined neutral palette — every section is merchant-editable through the native Shopify theme editor.

Theme: khay Version 1.0.0 Dawn architecture Responsive RTL-aware
Multi-language: The theme is fully compatible with Shopify's native multi-language capabilities. Enable and configure additional locales from Shopify Admin → Settings → Languages; the theme itself ships with English (en.default.json) and uses translation keys throughout.

01 — Getting started

Installation

Install the theme on any Shopify store in a few minutes. Preview first, publish when ready.

Shopify Admin

  1. Download the themeClone or download this repository as a ZIP.
  2. UploadGo to Online Store → Themes → Add theme → Upload zip file.
  3. PreviewClick Preview to inspect the storefront before publishing.
  4. CustomizeOpen the theme editor to adjust content, colours and imagery.
  5. PublishPublish when the store is ready.

Shopify CLI (developers)

CommandPurpose
shopify theme devRun a local development server with live preview
shopify theme checkRun Shopify's static analysis (0 errors)
shopify theme pushUpload as an unpublished theme
shopify theme publishPublish the theme

02 — Homepage

Sections overview

The default homepage (templates/index.json) is composed of the following sections. Reorder, hide or remove any of them from the theme editor.

kv-hero-reel

Hero Reel

Cinematic full-height slideshow. Settings: stage height, autoplay, seconds per slide, control-bar background & text. Blocks: image / fallback asset, title, link label & URL, top-bar note.

kv-campaign

Campaign Editorial

Editorial collage with campaign copy. Settings: heading, link label & URL, description, background/text/muted colours, top & bottom padding. Blocks: collage image with width, push-down, alignment, link.

press-banner

Press & Quotes

Rotating press quotes plus a scrolling publication row. Settings: eyebrow, quote timing & size, layout, margins, hairlines, logo row height/size/gap, loop speed & direction, and six colour controls.

countdown-banner

Drop Countdown

Full-bleed cinematic countdown band. See the dedicated section below.

new-arrivals-static

New Arrivals

"Just Dropped" product carousel. Settings: source collection, sort mode, product limit, eyebrow & heading, View All link, vendor/size toggles, padding. Product cards crossfade to a second image without zoom.

khavay-split-cards

Split Cards

Split editorial category cards with an optional mega-menu panel. Settings: colour scheme, CTA text, panel eyebrow/label, padding. Blocks: image, title, collection, link, menu, panel title & image.

khavay-editorial-hero

Editorial Hero

Large campaign feature ("Cut Once, Worn Forever"). Settings: eyebrow, heading, description, CTA, campaign image/alt/caption, desktop image height, colour scheme and four colour controls. Layout is LTR/RTL-aware (copy right, image left in LTR).

collection-list

Explore the House

Collection tile grid. Settings: title, heading size, eyebrow, image ratio, desktop/mobile columns, colour scheme, fallback image toggle, tile CTA label, product counts, View All, and full colour/spacing controls. Blocks: collection, custom image, asset path, subheading.

brand-story

Brand Story

Philosophy hero ("THE ESSENCE OF KHAVAY"). Settings: wide photograph, eyebrow, headline, short paragraph, link label & URL, background/ink/muted/accent colours, top & bottom padding.

khavay-lookbook

Lookbook

Editorial image grid. Settings: eyebrow, heading, subtitle, colour scheme, background, light-text toggle, padding. Blocks: image, title, details, link.

testimonials-slider

Testimonials

Client-story slider. Settings: eyebrow, heading, six colour controls, auto-advance timing, reduced-motion multiplier, margins and padding, photo shape & focal point. Blocks: quote, name, badge, image(s), product, link label.

client-care

Client Care

Pre-footer service band ("At Your Service"). Settings: eyebrow, heading, small mark image, three services (title, sentence, link label & URL), background/ink/muted/accent colours, padding.

03 — Countdown feature

Drop Countdown band

The horizontal countdown band (countdown-banner.liquid, "Drop Countdown") combines a live timer with a drifting photographic frame. It is driven entirely by section settings — no code edits required.

Copy & call to action

SettingTypeDefault
eyebrowtextLimited Drop
headingtextThe Autumn Editorial Drop
promo_texttextareaFour looks, cut once…
link_labeltextShop the Drop
linkurl— (falls back to all products)

Countdown

SettingTypeDefault
countdown_endtext— (format YYYY-MM-DD HH:MM, store local time)
countdown_expiryselectkeep_counting
countdown_expiry_texttextThis drop has ended

On expiry you can keep counting, hide the section, or keep counting while showing the expiry text.

Motion

SettingTypeDefault
motioncheckboxtrue
drift_durationrange 6–24 s9 s
zoomrange 1.2–1.5×1.2×
slide_intervalrange 3–15 s7 s
show_pausecheckboxtrue
Use landscape images at least 2000 px wide. The frame zooms as it moves, so small or portrait sources will soften or crop poorly. Around 9 seconds per drift is the sweet spot — slower reads as a still image.

Legibility & layout

SettingTypeDefault
scrimselectstrong (none / light / medium / strong)
text_alignselectleft (left / centre)
media_ratiorange 1.2–2.6 : 12 : 1
media_radiusrange 0–120 px0 px
pad_bottom — space under the textrange 16–200 px56 px
pad_top — space above text when no imagerange 24–240 px128 px

Colours

SettingDefault
section_bg — background (no image only)#171410
content_color — text (no image only)#FFFFFF
accent_color — eyebrow#FFFFFF

Media blocks (up to 6): image, fallback_asset (theme asset filename), alt, and direction (push / right / left / up / down / diagonal). With no blocks the band renders as a flat colour field; with one it drifts in place; with several it crossfades between frames.

04 — Theme settings

Global settings & design tokens

Configured in config/settings_schema.json and editable under Theme editor → Theme settings.

Logo, logo width, favicon, colour schemes, typography, buttons, cards, animation, and social links — inherited from the Dawn-based foundation.

Support
