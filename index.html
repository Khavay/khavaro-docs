THEME AT A GLANCE

Designed for merchant control

Khavaro keeps the storefront visually deliberate while exposing the important merchant-facing controls through Shopify's Theme Editor. Images, collections, navigation, typography, colors and section content are intended to be configurable without editing theme code.

DOCUMENTATION PRINCIPLE

Configure first. Edit code only when necessary.

Normal merchant setup should be handled through Shopify's native admin, Theme Editor, products, collections, menus, policies and market settings. Code changes are intended for advanced development and maintenance workflows.

Merchant setup

Use Shopify admin and the Theme Editor for everyday configuration.

Storefront content

Use real products, collections, navigation and brand content before publishing.

Support-ready

Keep the theme version and reproduction details available when reporting an issue.
