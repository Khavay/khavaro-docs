# Khavaro Documentation

Official documentation package for the **Khavaro Shopify theme**.

## GitHub Pages

This folder is intentionally self-contained and can be published as a static GitHub Pages site.

1. Create a public GitHub repository, for example `khavaro-docs`.
2. Upload the contents of this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the default branch and the `/ (root)` folder.
6. Save and wait for GitHub Pages to publish the site.
7. Use the resulting public `https://...github.io/.../` address as Khavaro's documentation URL.

## Documentation URL in Shopify

After the GitHub Pages URL exists, replace the temporary `theme_documentation_url` value in Khavaro's `config/settings_schema.json` with the real public URL.

Do not use the Shopify Help Center URL as the final documentation URL.
