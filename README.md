# Khavaro Documentation

Official merchant-facing documentation for the **Khavaro Shopify theme** by **Khavay**.

## Publish with GitHub Pages

1. Create or open a public repository, for example `khavaro-docs`.
2. Upload the contents of this package to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the default branch and `/ (root)`.
6. Save and wait for the GitHub Pages deployment.
7. Use the resulting public GitHub Pages URL as the theme documentation URL.

## Design system

The documentation uses a restrained Khavaro black, white and gray visual system. Links are explicitly styled in CSS so browser-default blue link colors do not appear in normal text, navigation, buttons or support controls.

## Shopify Theme Store support

Shopify requires Theme Store themes to provide public documentation and a public support contact form, and both must be linked from the Theme Store listing. The support form should collect enough information to investigate merchant issues, including contact details, store URL, problem description and useful screenshots/files.

Keep this documentation synchronized with future theme releases and changes to Theme Editor settings.
